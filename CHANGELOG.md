# Changelog

All notable changes to `@zerobertoo/r6operators` are documented here.

---

## [1.0.0] — 2026-05-09

Initial public release as a maintained fork of [marcopixel/r6operators](https://github.com/marcopixel/r6operators).

### Added

- Full operator roster from launch through **Y11S1** (83 operators), including the most recent additions:
  - **Y11S1** — Solid Snake (Operation Chimera Protocol)
  - **Y10S3** — Denari (Operation Dread Factor)
  - **Y10S1** — Rauora (Operation Prep Phase)
  - **Y9S3** — Skopos
  - **Y9S2** — Striker & Sentry (Operation New Blood)
  - **Y9S1** — Deimos (Operation Commanding Force)
  - **Y8S4** — Tubarão (Operation Deep Freeze)
  - **Y8S3** — Ram (Operation Heavy Mettle)
  - **Y8S2** — Fenrir (Operation Dread Factor)
  - **Y8S1** — Brava (Operation Commanding Force)
  - **Y7S4** — Solis (Operation Solar Raid)
  - **Y7S3** — Grim (Operation Brutal Swarm)
  - **Y7S2** — Sens (Operation Vector Glare)
  - **Y7S1** — Azami (Operation Demon Veil)
  - All original operators from **Release** through **Y6S4**
- `@zerobertoo/r6operators-react` v1.0.3 — React component wrapper (`<R6Operator />`)
- Monorepo structure with npm workspaces
- Full TypeScript types (`IOperator`, `IOperatorMeta`, `IOperatorBio`, `IOperatorRatings`)
- ESM, CJS, and UMD bundles
- Optimized SVG icons via SVGO (350×350 viewBox)
- GitHub Pages live demo
- Automated publish workflow via GitHub Actions
